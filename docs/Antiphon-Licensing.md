# Licensing

## Evaluation mode is what's live today

Antiphon currently runs in **evaluation mode**: no license key required, full function, nothing
disabled or sabotaged, notice-only. This repository's three samples all run with
`licenseKey: null` throughout, and produce complete, unrestricted output.

## Commercial licensing

Evaluation mode is what's live today; the commercial/paid tier is not yet available for purchase.
If you're interested in commercial use, or want to know when it becomes available, see
<https://clockworkotterfoundry.com/antiphon/> for current status and how to get in touch.

This repository's own code — the three sample projects, its `README.md`, and `PACKAGES.md` — is
MIT-licensed; see [`LICENSE`](../LICENSE). Antiphon itself is proprietary, closed-source commercial
software. These samples merely consume its public API surface as an evaluator would.
