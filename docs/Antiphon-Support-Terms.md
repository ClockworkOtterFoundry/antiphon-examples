# Support Terms

Antiphon is currently distributed in **evaluation mode**: published, runnable, and free to use
without a license key, but without a service-level agreement. There is no guaranteed response time
or uptime commitment for evaluation-mode use.

If you run into a problem while evaluating the SDK, the samples in this repository — and their
individual `README.md` files — are the best first place to check whether your results match the
documented, expected output.

For questions about moving beyond evaluation mode, including what support terms come with a
commercial license, see <https://clockworkotterfoundry.com/antiphon/>.
